# Lær at skrive med 10 fingre

A touch-typing web app, Danish first, built for kids (7 and 10) but usable by anyone.
Live at https://torbenoestergaard.github.io/learn-touch-typing/.

**The plan, milestones and handover notes are in [docs/ROADMAP.md](docs/ROADMAP.md).** When asked to
"start milestone X", follow that file's workflow section.

## Commands

```bash
npm run dev      # http://localhost:5173/learn-touch-typing/ (also "dev" in .claude/launch.json)
npm test         # Vitest
npm run build    # tsc + vite build
npm run lint     # oxlint
```

## Structure

- `src/engine/`: the typing session reducer and stats. Pure, no DOM.
- `src/content/`:
  - the exercise generator (seeded)
  - LIX
  - `da/modules.ts`: the learning path
  - `da/words.json`: generated by `scripts/build-wordlist.ts`
  - `da/stories.ts`
- `src/storage/profiles.ts`:
  - localStorage persistence (`ltt:v1`)
  - progress
  - story records
  - `history` (an attempt log)
- `src/components/`: React screens. `App.tsx` switches between screens with a `Screen` union.
- `src/i18n/da.ts`: **all** user-facing text.
- `src/layouts/da.ts`: the Danish keyboard and which finger presses each key.
- `src/config.ts`: thresholds and tuning values.

## Conventions

- **Logic and tests:** keep logic out of components and put it in pure modules with Vitest tests.
- **Text:** never hard-code UI text in components; add it to `i18n/da.ts`.
- **Stored data:** kids have real progress in localStorage.
  - New `Profile` fields must be optional, with defaults applied when read (see `soundOn`, `speedUnitOf`).
  - Otherwise, migrate the data.
- **Kid-safe content:** any new words or text must pass the blocklist and rudeness filter.
- **Typing screen:** don't show live speed or errors while typing.
- **Speed:** stored internally as keystrokes per minute (`kpm`). Display it with `formatSpeed(kpm, speedUnitOf(profile))`.
- **Verify:** check UI changes in the browser before calling them done.
- **Releases:** bump `version` in `package.json` and add a `CHANGELOG.md` entry with each release.
